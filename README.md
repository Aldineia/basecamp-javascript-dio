# Comparador de Números - Desafio DIO

Este repositório contém a solução para o desafio de projeto de JavaScript do curso de desenvolvimento da **DIO (Digital Innovation One)**.

##  Sobre o Projeto
O objetivo da atividade é criar uma função em JavaScript que recebe dois números como parâmetros e realiza algumas validações:
1. Verifica se os dois números são iguais ou diferentes.
2. Soma os dois números.
3. Verifica se a soma é maior ou menor que 10.
4. Verifica se a soma é maior ou menor que 20.
5. Retorna uma frase formatada unindo todas essas informações.



## Tecnologias Utilizadas
* **JavaScript** (Node.js)
* **VS Code** (Editor de código)
* **Git e GitHub** (Controle de versão)
